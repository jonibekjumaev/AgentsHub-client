# AgentsHub — client

Next.js 14 (Pages Router) client of **AgentsHub**, a marketplace for AI agents: creators list agents,
businesses post briefs, members follow, like, comment and chat. The API is a separate NestJS + GraphQL
repo (`AgentsHub`).

- Rules for contributors (and Claude Code): [`CLAUDE.md`](CLAUDE.md)
- API contract and decisions D-01…D-33: [`docs/FRONTEND_MIGRATION.md`](docs/FRONTEND_MIGRATION.md)
- Design system and page map: [`docs/DESIGN.md`](docs/DESIGN.md), mockups in `docs/design/`

## Stack

React 18 · TypeScript (strict) · MUI 5 + Emotion · Apollo Client 3 (SSR per request, token only in the
browser) · GraphQL Codegen (client preset) · react-hook-form + zod/mini · next-i18next (`en`, `ko`, `uz`) ·
Vitest + Testing Library · yarn.

## Getting started

```bash
yarn install
cp .env.example .env.local   # then edit if your API is not on localhost:3005
yarn dev                     # http://localhost:3000
```

| Variable | Example | Used for |
|---|---|---|
| `NEXT_PUBLIC_API_URL` | `http://localhost:3005` | uploads (`/uploads/...`), next/image |
| `NEXT_PUBLIC_API_GRAPHQL_URL` | `http://localhost:3005/graphql` | Apollo |
| `NEXT_PUBLIC_API_WS` | `ws://localhost:3005` | community chat |
| `NEXT_PUBLIC_SITE_URL` | `http://localhost:3000` | canonical / hreflang URLs, sitemap |

`src/config/env.ts` is the only module that reads `process.env`; a missing variable fails at start-up.

## Scripts

| Command | What it does |
|---|---|
| `yarn dev` | dev server on port 3000 |
| `yarn codegen` | regenerates `src/gql` from the running API's schema — run after changing any `graphql(...)` document |
| `yarn typecheck` | `tsc --noEmit` |
| `yarn lint` | `next lint` |
| `yarn test` | Vitest, once (`yarn test:watch` while working) |
| `yarn build` / `yarn start` | production build / server |
| `yarn analyze` | build + bundle treemaps in `.next/analyze/` |

Don't run `yarn build` while `yarn dev` is running (they share `.next/`).

## Structure

```
src/
  pages/      routing only: params, getServerSideProps / getStaticProps, layout
  features/   agents, briefs, comments, creators, follows, community, account, admin, dashboard, home, info, seo, auth
              each: components/ graphql/ hooks/ lib/ index.ts (the only import surface for other features)
  shared/     ui/, layout/, lib/
  apollo/ auth/ config/ theme/
  gql/        generated by codegen — never edit
public/locales/{en,ko,uz}/*.json
```

## Deploy

Any Node 20 host that runs `next start` (Vercel, a VPS behind nginx, Docker):

1. Set the four `NEXT_PUBLIC_*` variables **at build time** (Next inlines them into the bundle).
2. `yarn install --frozen-lockfile && yarn build && yarn start` (port 3000 by default, `-p` to change).
3. Put the site behind HTTPS. The API's WebSocket then has to be `wss://`, and the API must allow the site's
   origin (CORS) and serve `/uploads`.
4. `robots.txt` allows indexing only when `NODE_ENV=production`; check `/sitemap.xml` after the first deploy.

## Git flow
